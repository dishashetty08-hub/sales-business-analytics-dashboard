BCA portfolio project using Excel, SQL/MySQL and Power BI.

## Included

- Professional Excel workbook with formatted data and summary sheet
- CSV dataset for database import
- MySQL table and analysis queries
- Power BI setup guide

## Dashboard
- Total Sales
- Total Profit
- Total Orders
- Total Quantity
- Monthly Sales Trend
- Sales by Category

- Top 10 Products
- Interactive slicers

## Skills demonstrated
Excel, SQL, MySQL, Power BI, data cleaning, aggregation, dashboard design and business analysis.
